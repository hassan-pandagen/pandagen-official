# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Email
[info@pandacodegen.com](mailto:info@pandacodegen.com) with the subject
`Security report` and include:

- the affected URL, route, or component;
- clear reproduction steps;
- the expected and observed behavior;
- the potential impact; and
- any suggested mitigation.

Do not include credentials, personal data, or destructive proof-of-concept
payloads. Use test data and the minimum activity needed to demonstrate the
issue.

Reports are triaged by severity and reproducibility. When contact details are
provided, PandaCodeGen will use them for material status updates. No response or
remediation SLA is promised by this public policy; reporters are asked to allow
a reasonable fix window before disclosure.

## Supported version

Security fixes target the code deployed from the repository's current default
branch. Older deployments and forks are not supported.

## Scope

The public website and its first-party API routes are in scope. Third-party
services are governed by their own disclosure programs. Social engineering,
denial-of-service testing, automated traffic that degrades service, and access
to other people's data are out of scope.
