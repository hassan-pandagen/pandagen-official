## Rules

- A claim is **Approved** only when an accountable owner supplies dated evidence, an approver records acceptance, and a review or expiry date is assigned.
- A page in this repository is not independent evidence for another page.
- Metadata, visible content, JSON-LD, images, FAQs, email copy, and external profiles must use the same approved fact.
- Mutable vendor terms, prices, laws, security guidance, reviews, market figures, and product capabilities require a current primary source.
- Results require permission plus the subject, period, baseline, method, source data, limitations, and review date.
- If approval or evidence is missing, remove the claim or use the allowed temporary wording below.
- Confidential records and personal data belong in an access-controlled evidence system, not this public repository.
