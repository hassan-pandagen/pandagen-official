Research date: **18 September 2026**. Target: `/services/wordpress-migration`. This is a read-only market/content audit; no application files were changed.

## What the evidence supports

The exact service phrase has a strong provider-selection intent. The observed offers compete on migration scope, CMS/editor continuity, search continuity, credible work, price, and an assessment CTA. A stronger service page should make those buying decisions easier. This research does **not** establish why PandaCodeGen averages position 12.2 or predict a top-five ranking.

## Priorities to test against PandaCodeGen's live page

These are competitive requirements to compare with the main audit, **not assertions that every item is currently missing**.

1. **Clarify the purchase immediately.** Candidate title: `WordPress to Next.js Migration Services | PandaCodeGen`. Candidate H1: `WordPress to Next.js Migration Services`. First paragraph should identify site type, actual CMS options, core migration scope, and the next step. Preserve the existing URL unless the technical audit establishes a reason to move it.
2. **Show what happens to editing.** A compact retained-WordPress / replacement-CMS / repository-content comparison can answer admin, previews, roles, publishing, maintenance ownership and ongoing costs. Offer only paths the team can deliver. This addresses a repeated competitor buying question.
3. **Make scope inspectable.** Show inventory → architecture → build/migrate → validation → cutover → support with tangible outputs. Useful samples include an anonymized URL map, plugin-function disposition, content-field mapping and signed-off editor workflow. Clearly label sample artifacts; never present them as client outcomes.
4. **Put relevant proof near the offer.** Prefer a named WordPress migration case with source/destination, URL/template counts, what changed, date, measured mobile/desktop lab versus field results, and a consistent pre/post organic baseline. If that proof does not exist, publish honest process artifacts and adjacent work with clear labels. No invented clients, ratings, traffic gains or claims of causality from framework choice.
5. **Qualify price and timeline.** Existing PandaCodeGen pricing should explain included pages/templates/content, CMS setup, integrations, revisions, launch support, exceptions and ongoing costs. Competitor prices vary radically with scope; the table is not a market average or evidence PandaCodeGen should raise/lower prices.
6. **Give an assessment CTA a concrete output.** A site URL plus a short brief should lead to a fit decision, risk/scope outline, CMS recommendation and quote, if that matches the real sales process. Keep phone-free submission available if supported. Only state response times that operations can meet.
7. **Consolidate the cluster.** Service owns hiring; cost guide owns pricing detail; tutorial owns implementation; case study owns proof. Link contextually between them. Avoid new pages for punctuation, singular/plural, agency/service or unsupported locations. Review GSC page/query overlap before diagnosing cannibalization.

## Technical claims to keep precise

Google documents temporary ranking fluctuations during significant site changes and recommends URL mapping, testing and monitoring. Preserve unchanged routes; use appropriate permanent redirects for changed routes rather than promising a redirect for every old URL. No competitor guarantee establishes immunity from ranking changes. [Google site-move documentation](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes)

WordPress has distinct resources beyond posts, including pages, media, taxonomies and users. A migration scope should identify the actual resources and custom functionality being moved. [WordPress REST API reference](https://developer.wordpress.org/rest-api/reference/)

Publishing previews require an implemented workflow; they are not automatically preserved by choosing a framework. Next.js documents Draft Mode for previewing draft content. A buyer-facing explanation can stay simple while the acceptance checklist verifies it. [Next.js Draft Mode](https://nextjs.org/docs/app/guides/draft-mode)

Top five is an outcome to measure against a stable country/device/date definition, not a content-delivery promise. This subtask did not measure backlinks, competitor conversion rates, current Google positions, or PandaCodeGen's indexing/technical condition; those cannot be inferred from the pages above.
