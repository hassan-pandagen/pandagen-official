# Homepage audit consolidation (Sep 15, 2026)

This folder combines two audits conducted on September 15, 2026:
1. **Homepage positioning** — brand messaging, benchmark comparisons, technical review
2. **Homepage keyword language** — vocabulary choices, demand evidence, recommended copy

Both audits informed the same homepage revision. Start with `README.md` (keyword language recommendations) which drives copy decisions, then reference supporting files by topic:

| Topic | Files |
|---|---|
| Keyword evidence and demand | `preserved-keyword-data.md`, `migration-intent.md`, `new-build-intent.md` |
| Positioning benchmarks | `business-agency-benchmark.md`, `technical-studio-benchmark.md` |
| Copy recommendations | `recommended-copy.md`, `recommended-section.md`, `pricing-follow-up.md` |
| Current-page review and technical | `current-page-review.md`, `follow-up-audit.md`, `render-check.md` |

The two audits reached the same conclusion: position the homepage as a company introduction that names broad service categories (website design, redesign, migration, custom development, ecommerce) without repeating every platform name. Use clear keyword language (redesign, rebuild, migration) rather than ambiguous terms like "convert". Link to service pages and guides for platform-specific detail.

**Status:** Recommendations implemented in the working tree as of Sep 19, 2026.
