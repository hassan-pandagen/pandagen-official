### FAQ citations and crawl budget

Useful answers in visible HTML remain suitable source material for AI answers. Google says there is no special schema required for generative Search, so FAQ markup is not presented as an established citation advantage. See [Google's generative Search guide](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide). Preserve accurate matching markup where useful, but invest in the underlying answer, evidence, authorship and independent references.

At this site's size, crawl budget is unlikely to be the main constraint. Keeping a page's URL during a redesign does not make it a newly discovered URL; Google can recrawl and reevaluate it. Build the useful core before release, preserve important URLs and redirects, update genuine modification dates and monitor indexing after launch. Do not add a large speculative keyword inventory just to avoid future recrawls. [Google's crawl-budget guidance](https://developers.google.com/crawling/docs/crawl-budget).

## AEO and citation readiness

Google's current guidance emphasizes distinctive first-hand value and ordinary search fundamentals. It does not prescribe a special AI schema, an exact word count or a fixed paragraph size. Its guidance also says `llms.txt` does not affect Google Search visibility. Prioritize useful evidence and readable answers over adding more AI-specific files. [Google AI optimization guide](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide).

**FAQ rich results were retired from Google Search on 7 May 2026.** The documentation was removed in June. Keep useful visible FAQs, but do not sell their markup as a Google rich-result benefit. Existing FAQ schema need not be removed as an emergency; avoid investing in more of it solely for that retired feature. [Google documentation updates](https://developers.google.com/search/updates).

## Measurement that answers business questions

Use qualified US enquiries, proposals and acquired customers as the business outcomes. Record which page and offer the prospect entered through. A traffic increase with only developer tutorial readers may help distribution but does not establish commercial success.

For search, monitor index coverage, target-page visibility and relevant query families after launch. Future Search Console measurement is appropriate; it is separate from using your current query data to discover this opportunity set. If Google's Generative AI report is available in the property, compare its defined metrics without equating impressions to brand recommendations. Check current product availability instead of assuming every property exposes the same report.

Bing's AI Performance preview provides citation-related views, including topics and intent reporting for supported Microsoft surfaces. Its citation share is not a general ranking score, traffic share, or a list of named competitors. Use its definitions when interpreting the data. [Bing AI visibility reporting](https://blogs.bing.com/search/2026/6/New-AI-Visibility-Insights-in-Bing-Webmaster-Tools-Intents-Topics-Citation-Share-Compare/).

Create a fixed US buyer prompt panel covering editor usability, platform choice, migration cost, retained CRM/commerce, portals, ownership and agency selection. Run each prompt on a named surface with date, locale and search setting recorded; repeat on separate days. Save the actual answer and cited URLs. Report: **brand mentioned / recommended as a provider / own URL cited / third-party description cited** separately. A citation that supports an answer recommending someone else is still different from a recommendation of your agency. This panel is a future measurement protocol, not a result of this audit.

Sample prompts: “Who can build a custom website my marketing team can edit?”; “What does a small Next.js and Sanity website cost in the US?”; “Can we keep WooCommerce admin and replace the frontend?”; “Do we need Sanity and Supabase for a customer portal?”; “What should a small agency receive in a white-label website handover?” Avoid stuffing your own name into every discovery prompt.
